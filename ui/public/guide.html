Langue

Choisis Français ou English en haut de l’application, dès la configuration. Le choix est mémorisé dans ce navigateur et le changement conserve les brouillons. Les CV, messages, annonces et documents restent dans leur langue d’origine ; demande à ton assistant IA de traduire leur contenu si besoin.

Ton IA, tes sources

  1. Choisis DeepSeek, Kimi, Claude ou OpenAI.
  2. Renseigne ta clé API et un modèle conversationnel.
  3. Teste et enregistre la connexion. Ce court appel peut être facturé.
  4. Choisis ton pays, ton métier, les plateformes et tes préférences de travail. Enregistre ta clé Bright Data séparément de la clé IA. France Travail est proposé pour la France.
  5. Décris ton parcours et active ton espace.

Aucune recherche automatique à l’installation. Les abonnements aux applications de chat ne remplacent pas une clé API.

LinkedIn et Indeed

Les collecteurs Bright Data recherchent les annonces publiques selon le pays et le métier choisis : jusqu’à 20 annonces par plateforme et métier. Ils n’utilisent pas ton compte LinkedIn ou Indeed. Active les scrapers correspondants dans ton compte Bright Data, puis utilise le test de connexion. Les résultats peuvent être facturés par Bright Data ; le plafond local compte les appels, pas les euros. La couverture dépend du pays et du fournisseur.

La langue de l’aide et des documents se règle dans les critères de recherche, indépendamment de la langue de l’interface.

Au quotidien

Commence par ton profil, puis demande une recherche dans la conversation. Enregistre les pistes utiles et prépare un CV ou une lettre depuis une fiche. La veille permet de choisir la source et le rythme. Chaque fournisseur sélectionné doit être configuré.

Les brouillons de courrier restent à relire et à confirmer. L’IA ne dispose d’aucun outil d’envoi.

Ce qui reste chez toi

Profils, conversations, documents et clés sont dans le volume Docker de ton installation. Les clés ne sont pas chiffrées sur disque : garde tes sauvegardes privées. L’IA reçoit le contexte nécessaire et les sources reçoivent les critères de recherche.

Les coûts dépendent de tes fournisseurs. Le compteur local Bright Data ne représente pas ton solde en euros.

Arrêter et relancer

Depuis le dossier du paquet : docker compose stop, puis docker compose up -d. Les données sont conservées. Le README contient la procédure de sauvegarde et de restauration.
